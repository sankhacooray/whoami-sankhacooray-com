# soundarya — skills profile

**What it is:** A personal academic website for another researcher (Soundarya Ramesh) — originally a Jekyll (Hyde theme) site, rebuilt by Sankha as a modern, framework-free HTML5/CSS/JS static site for GitHub Pages.

**Sub-projects scanned:** 2 — a git-tracked GitHub Pages repo (`soundaryaramesh.github.io`, original Jekyll on `master` + modern rebuild on `dev`) and a standalone working copy of the same rebuild (`soundarya-web-html5`, no git).

**Sankha's role & contribution:** Co-developer / rebuild author. The original Jekyll site (~131 commits, 2018–2025) was authored entirely by the site owner, Soundarya Ramesh. Sankha contributed a single large commit (2026-05-29) that reconstructs the whole site as a modern static build — new HTML5 pages, a ~580-line hand-written CSS design system, and vanilla JS interactions — built FOR someone else.

**Collaborative?:** Yes — authors are Soundarya Ramesh (original Jekyll content/site) and Sankha Cooray (modern static reconstruction). Sankha focused on: front-end rebuild, responsive layout, CSS design system, and JS UI behavior; he did not author the underlying academic content.

**Domains:** Web/Frontend, Design/UX

**Core skills & tech:**
- Semantic HTML5 and hand-written modern CSS (custom properties/theming, responsive sidebar layout, shadow/motion design tokens)
- Vanilla JavaScript (IIFE module pattern, no framework) — mobile nav toggle, IntersectionObserver scroll-reveal, accessible show-more toggles
- Accessibility practices (ARIA attributes, keyboard/Escape handling, `aria-expanded` state)
- Static-site tooling: GitHub Pages, prior Jekyll structure, web fonts (Google Fonts) and Font Awesome icons
- Local dev workflow via VS Code launch/tasks configs and a simple `python3 -m http.server` static server

**Capabilities demonstrated (generic):**
- Migrating a legacy templated site to a clean, dependency-free static build while preserving brand palette and content
- Designing a cohesive visual system from scratch (color tokens, typography, spacing, shadows)
- Building responsive, accessible navigation and progressive-enhancement UI without libraries
- Structuring a multi-page academic/portfolio site (home, publications, blog index, individual posts, 404)

**Commit footprint:** ~1 commit by Sankha (one comprehensive rebuild); active 2026. Original site content by another author spans 2018–2025.

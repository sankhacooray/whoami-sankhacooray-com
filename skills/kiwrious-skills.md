# kiwrious — skills profile

**What it is:** A science-education hardware/sensor ecosystem — USB plug-and-play sensors for schools plus the web platform, SDK, docs, and content sites that let learners measure and visualise the physical world in a browser.

**Sub-projects scanned:** 12 — a Web Serial sensor SDK (TypeScript, published to npm/ESM/CDN), a Fastify API backend, two Vue measurement web apps, a Vue learning platform, a developer documentation site, several static marketing/landing sites, and a forked block-coding play environment.

**Sankha's role & contribution:** Lead / primary developer. Solo or dominant author across most repos: the SDK, API, CDN/ESM/docs, and measurement apps are ~100% his; on the largest content repo he authored roughly two-thirds of commits (~850 of ~1300). The forked block-coding environment (Scratch/MIT VM) is upstream code with only a handful of his integration commits.

**Collaborative?:** Yes — the learning platform and some marketing sites had co-contributors (research-lab colleagues). Sankha focused on: the Web Serial sensor SDK, the Fastify backend/API, the Vue measurement apps, developer docs, and the CDN/ESM/npm distribution.

# stakco-template-html5 — skills profile

**What it is:** A minimal boilerplate/starter template for the Stakco family of static HTML5 mini-apps — a single-page shell with shared theming, PWA manifest, and a one-command GitHub Pages deploy script.

**Sub-projects scanned:** 1 — a static HTML5 app template (`src/index.html` + `src/manifest.json`) plus a Node deploy script.

**Sankha's role & contribution:** Solo — 2 of 2 commits by Sankha. Sole author.

**Collaborative?:** No, solo.

**Domains:** Web/Frontend, Design/UX, DevOps/Infra, Software Development

**Core skills & tech:**
- Semantic HTML5, responsive meta setup, SEO/social meta (Open Graph, Twitter Card), theme-color
- Installable PWA scaffolding via `manifest.json`
- Shared design-system consumption from a CDN (`stakcos.com` theme.css, Font Awesome, html2canvas)
- Node.js deploy automation: shallow + sparse `git clone` of the `gh-pages` branch, copy a subdir, push — publishing the template into the shared GitHub Pages site
- `.nojekyll` / GitHub Pages static hosting conventions

**Capabilities demonstrated (generic):**
- Standardising a reusable app skeleton so new mini-apps start from a consistent, share-ready baseline
- Wiring rich link-preview metadata and PWA installability into a static page
- Automating deploy of a subfolder into a shared Pages repo without full clones
